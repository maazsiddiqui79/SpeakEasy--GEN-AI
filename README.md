# 🎙️ SpeakEasy — AI-Powered Voice Communication & Training Platform

> **Train Under Pressure. Speak Clearly. Build Confidence.**

SpeakEasy is an **AI-powered, voice-first communication training platform** designed to help users improve their speaking, interview, presentation, debating, fluency, and communication skills through realistic interactive sessions.

Instead of simply pointing out mistakes, SpeakEasy analyzes how a user speaks and provides **actionable feedback, recovery techniques, filler-word analysis, pacing insights, and alternative ways to phrase responses**.

# 📖 Overview

**SpeakEasy** is a voice-first AI platform for practicing real-world communication scenarios like interviews, presentations, debates, and difficult conversations.

The platform uses **voice interaction, speech analysis, and AI coaching** to identify communication issues and provide actionable feedback for improvement.

The system focuses on practical communication problems including:

* Excessive filler words
* Repeated sentence restarts
* Weak vocabulary
* Poor pacing
* Lack of fluency
* Weak argument structure
* Difficulty speaking under pressure / organizing responses

SpeakEasy offers **specialized training modes for practicing communication skills across different real-world scenarios.**

> 🎓 Developed as part of the **Gen AI Competition at the TCET Zephyr event**.

# 🧠 Speech Intelligence

SpeakEasy does more than basic speech recognition.

The platform analyzes the user's transcript and identifies communication patterns that may affect clarity and confidence.

## 🔍 Filler Detection

Detects and tracks commonly used filler words such as:

* `like`
* `basically`
* `actually`
* `you know`

Filler occurrences can be grouped and analyzed to identify repeated speech patterns.

---

## 💡 "Say This Instead"

SpeakEasy does not stop at identifying mistakes.

For detected communication problems, it provides **contextual alternative phrasing** that users can use to improve their response.

This changes the feedback from:

> "You made a mistake."

into:

> "Here is a clearer way to communicate the same idea."

---

## 🎯 Subtle Real-Time Feedback

The platform intentionally keeps real-time feedback minimal while the user is speaking.

Detailed analysis is presented after the speaking segment so that users can maintain their flow instead of constantly watching performance indicators.

---

# 🌐 Multilingual Support

# 📊 AI Performance Analysis

After a speaking session, SpeakEasy can analyze multiple communication characteristics.

| Analysis Area | Description                                          |
| ------------- | ---------------------------------------------------- |
| Filler Words  | Detects and counts common filler expressions         |
| Fluency       | Evaluates the overall flow of speech                 |
| Pacing        | Examines speaking speed and delivery                 |
| Vocabulary    | Identifies areas where word choice can be improved   |
| Structure     | Evaluates organization and clarity                   |
| Suggestions   | Provides actionable improvement techniques           |
| Focus Area    | Identifies areas requiring additional practice       |
| AI Feedback   | Provides contextual observations and recommendations |
| Overall Grammatical score | Provides an AI-generated performance indicator of Grammatical accuracy|

> **Note:** AI-generated scores and observations are estimates. They should be treated as practice guidance rather than professional certification, examination results, or definitive assessments.

# 🧠 System Workflow

### Step 1 — Select Training Mode

The user selects one of the available modes:

```text
Interview
Pressure
Opposite
Document
```

### Step 2 — Configure Session

Depending on the mode, the user selects:

* Topic
* Custom topic
* Preparation time
* Language
* Document

### Step 3 — Voice Interaction

The user speaks through the browser's voice interface.

```text
User
  │
  ▼
Speech Recognition
  │
  ▼
Transcript
```

### Step 4 — Speech Analysis

The transcript is analyzed for communication patterns.

```text
Transcript
    │
    ├── Filler Detection
    ├── Pacing Analysis
    ├── Vocabulary Analysis
    └── Structure Analysis
```

### Step 5 — AI Processing

Relevant session information is sent to the AI processing layer.

```text
User Response
      │
      ▼
Speech Analyzer
      │
      ▼
AI Processing
      │
      ▼
Contextual Response / Feedback
```

### Step 6 — AI Response

The AI generates an appropriate response, follow-up question, feedback, or recommendation depending on the selected mode.

### Step 7 — Performance Review

After the session, the user receives:

* Speech analysis
* Suggestions
* Focus areas
* AI feedback
* Performance indicators
* PDF report where available

# 🔐 Privacy, Data Protection & DPDP Act

Privacy is an important part of SpeakEasy because the platform can process user-generated information such as:

* Speech transcripts
* Interview responses
* Presentation material
* Uploaded documents
* AI-generated session information

SpeakEasy therefore includes dedicated privacy and legal documentation so users can understand how submitted information is handled.
The website exposes dedicated **Privacy Policy** and **Terms & Conditions** routes through the application footer.

## 🇮🇳 What is the DPDP Act?

The **Digital Personal Data Protection Act, 2023 (DPDP Act)** is India's primary legislation governing the processing of digital personal data.

The Act establishes requirements around the processing of digital personal data and provides rights and protections for individuals whose data is processed.

Among other provisions, the Act addresses:

* Notice and transparency
* Consent
* Purpose-specific processing
* Withdrawal of consent
* Data Principal rights
* Responsibilities of Data Fiduciaries
* Protection of personal data
* Grievance mechanisms

The Act specifies that consent should be **free, specific, informed, unconditional and unambiguous**, with a clear affirmative action.

The Ministry of Electronics and Information Technology has also published the **Digital Personal Data Protection Rules, 2025**, establishing additional requirements and an implementation framework.

## 🛡️ Why Privacy Matters in SpeakEasy

Unlike a conventional static website, SpeakEasy processes information generated directly by users during communication sessions.

For example:

```text
User Speech
    ↓
Speech Recognition
    ↓
Transcript
    ↓
Speech Analysis
    ↓
AI Processing
    ↓
Feedback
```

This makes transparency about data processing particularly important.

Users should understand:

* What information is processed
* Why it is processed
* Which third-party services may receive information
* How AI processing works
* What information should not be submitted
* How privacy documentation applies to the service

## 🔒 SpeakEasy's Data Approach

SpeakEasy is designed around a **session-based processing model** rather than maintaining a persistent user-content database.

The project's legal documentation states that the platform does not maintain a dedicated persistent database for storing interview responses, uploaded documents, voice transcripts, or session reports at its current stage. It also explains that information transmitted to third-party AI services may be subject to those providers' own retention policies.

SpeakEasy also documents its use of third-party AI processing, including the **Grok API provided by xAI** and the **qwen/qwen3.8-27b** model for applicable functionality.

### ⚠️ Important

The Privacy Policy and related legal documentation are intended to provide transparency about data handling. They should not be interpreted as a claim that the application is independently certified as legally compliant with every provision of the DPDP Act.

The project implements privacy-oriented practices because it accepts and processes user-generated information and aims to follow responsible data-handling principles.

# ⚙️ Installation & Setup

Follow the steps below to run SpeakEasy locally.

## 1. Clone the Repository

```bash
git clone https://github.com/maazsiddiqui79/SpeakEasy--GEN-AI.git
```

Navigate into the project:

```bash
cd SpeakEasy--GEN-AI
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Configure Environment Variables

Create a `.env.local` file in the project root.

Add the required AI/API credentials according to the project's environment configuration.

```env
GROQ_API_KEY=your_api_key_here
```

> Never commit API keys or other secrets to GitHub.

## 4. Start the Development Server

```bash
npm run dev
```

## 5. Open the Application

Open:

```text
http://localhost:3000
```

The repository is configured with the standard Next.js development, build, and start commands.

## 6. Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
